# 成绩管理系统（PHP 5.4 + CSV）

一个轻量级的学生成绩管理系统，**无需任何数据库**，数据存储在 CSV 文件中，兼容 PHP 5.4 及以上版本。

## 功能

- 学生成绩列表（按总分自动排名，同分并列）
- 添加 / 编辑 / 删除学生成绩记录
- 按姓名或学号搜索、按班级筛选
- 统计卡片：学生人数、各科平均分 / 最高分 / 最低分
- 不及格科目（< 60 分）红色高亮
- CSV 数据可用 Excel 直接打开编辑（UTF-8 带 BOM）

## 运行

**方式一：PHP 内置服务器（推荐，用于测试）**

```bash
cd oldphp
php -S localhost:8000
```

浏览器访问 <http://localhost:8000>

**方式二：Apache / Nginx**

将整个文件夹放入网站根目录（如 XAMPP 的 `htdocs`），访问对应 URL 即可。要求 PHP >= 5.4。

## 文件结构（共 8 个文件）

| 文件 | 说明 |
|------|------|
| `index.php` | 首页：成绩列表、统计、搜索筛选 |
| `edit.php` | 添加 / 编辑学生成绩 |
| `delete.php` | 删除确认 |
| `functions.php` | 函数库：CSV 读写、排名计算 |
| `config.php` | 配置：数据文件路径、科目定义 |
| `style.css` | 页面样式 |
| `README.md` | 本说明文档 |
| `data/students.csv` | 数据文件（首次访问时自动创建，含示例数据） |

## CSV 数据格式

`data/students.csv` 使用 UTF-8 编码（带 BOM），格式如下：

```
学号,姓名,班级,语文,数学,英语
2024001,张三,高一(1)班,92,88,95
```

- 表头行不可删除、不可改名
- 若用 Excel 编辑，保存时请保持 CSV 格式和列顺序不变
- 姓名 / 班级字段可包含逗号和双引号（系统按 RFC 4180 自动转义），但不要包含换行
- 手动新增学号建议保持数字，程序自动生成学号时会取「当前最大学号 + 1」

## 修改科目

编辑 `config.php` 中的 `$SUBJECTS` 数组即可增删科目，例如：

```php
$SUBJECTS = array(
    'chinese' => array('name' => '语文'),
    'math'    => array('name' => '数学'),
    'english' => array('name' => '英语'),
    'physics' => array('name' => '物理'),
);
```

> 注意：科目增删后需同步调整 CSV 文件的结构（表头与每行数据），或删除 CSV 文件让系统重新生成。

## 注意事项

- 本系统为学习演示用途，未做登录鉴权，请勿直接部署到公网。
- 并发写入 CSV 存在覆盖风险，适合小规模单机使用。
